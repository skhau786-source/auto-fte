================================================================================
                          QUICK START SNIPPET
================================================================================

Create a knowledge base and test:

  # 1. Create KB
  curl -X POST http://localhost:8000/ai/rag/knowledge-bases \
    -H "Authorization: Bearer TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"name": "Test KB"}'
  # Save KB_ID from response

  # 2. Upload document
  curl -X POST "http://localhost:8000/ai/rag/kb/KB_ID/documents" \
    -H "Authorization: Bearer TOKEN" \
    -d "title=Test&content=Hello world test content"

  # 3. Search
  curl -X POST "http://localhost:8000/ai/rag/kb/KB_ID/search?query=test" \
    -H "Authorization: Bearer TOKEN"

  # 4. Get context
  curl -X POST "http://localhost:8000/ai/rag/kb/KB_ID/augment?query=hello" \
    -H "Authorization: Bearer TOKEN"

✅ All 4 requests = RAG system is working!
